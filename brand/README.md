# Hyperblur · marca

HYPERBLUR em Chakra Petch Bold, caixa alta, branco sobre uma faixa azul com cortes diagonais.
A cauda começa depois do H: duas barras grossas e dezoito linhas com espaço igual, afinando e desbotando para a esquerda, como no logo de Cyberpunk: Edgerunners.
O texto já está convertido em curvas: os SVGs não dependem da fonte instalada.

## Arquivos

| Arquivo | Uso |
|---|---|
| `hyperblur-logo.svg` | lockup para fundos escuros (fundo transparente, texto branco) |
| `hyperblur-logo-light.svg` | lockup para fundos claros (fundo transparente, texto grafite) |
| `hyperblur-logo-dark-bg.svg` / `-light-bg.svg` | mesmos lockups com fundo sólido, para redes sociais e README |
| `hyperblur-mark.svg` | só o símbolo (faixa inclinada com três barras), 32×32, transparente |
| `favicon.svg` | símbolo em quadrado escuro arredondado |
| `avatar-dark.svg`, `avatar-dark-512.png`, `avatar-dark-1024.png` | avatar da organização no GitHub e no npm |
| `avatar-blue.svg`, `avatar-blue-512.png`, `avatar-blue-1024.png` | avatar alternativo, fundo azul |

## Regras rápidas

- A faixa é sempre azul sólido; o texto é branco ou grafite, nunca azul.
- Não use degradê nem blur na cauda: são traços retos, cortados na mesma diagonal da faixa, com opacidade em degraus.
- Em tamanhos pequenos (menos de 20 px de altura de letra) prefira o símbolo sozinho.
