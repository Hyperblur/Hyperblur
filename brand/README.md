# Hyperblur · marca

HYPERBLUR em caixa alta, preto sobre uma placa azul-gelo inclinada, com sombra magenta deslocada.
Atrás da placa, quinze listras diagonais que acendem do magenta ao azul, e duas linhas finas por baixo.
O nome já está convertido em curvas: os SVGs não dependem de fonte instalada.

## Arquivos

| Arquivo | Uso |
|---|---|
| `hyperblur-logo.svg` | logo completa, fundo transparente (feita para fundos escuros) |
| `hyperblur-logo-dark-bg.svg` / `-light-bg.svg` | a mesma logo com fundo sólido, para redes sociais e README |
| `hyperblur-mark.svg` | versão compacta: o H sobre a placa, com as listras |
| `favicon.svg` | o H sobre a placa, em quadrado escuro |
| `avatar-dark.svg`, `avatar-dark-512.png`, `avatar-dark-1024.png` | avatar da organização no GitHub e no npm |
| `avatar-light.svg`, `avatar-light-512.png`, `avatar-light-1024.png` | avatar alternativo, fundo claro |

## Regras rápidas

- A placa é sempre azul-gelo sólido e o nome é sempre tinta; a sombra é magenta, deslocada 9 px para baixo e para a direita.
- A inclinação das listras e da placa é a mesma (cerca de 22° em relação à vertical); não gire a logo.
- Em tamanhos pequenos (menos de 24 px de altura) use a versão compacta.
- A animação (listras acendendo, nome revelado com blur, glitch e código em ciano) vive em `LogoHero`, no site; os SVGs são a versão parada.
- Os códigos da animação usam Share Tech Mono (SIL Open Font License 1.1).
